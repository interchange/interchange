# upper

Alias for [uc](uc.md). Converts the value to upper case.

`upper` and `uc` name the same filter; `uc` holds the implementation. See
[uc](uc.md) for syntax, behavior, and examples.

## Example

    [filter upper]interchange[/filter]

produces:

    INTERCHANGE

## Source

Declared as an alias of `uc` in `code/Filter/uc.filter`
(`CodeDef upper Alias uc`).
