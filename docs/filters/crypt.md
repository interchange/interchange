# crypt

Hashes the value with the system `crypt()` function, using either a
supplied salt or a random one.

## Syntax

    [filter crypt]TEXT[/filter]
    [filter crypt.SALT]TEXT[/filter]
    [value name=field filter="crypt"]

The optional dotted argument `SALT` supplies the two-character salt. When
it is omitted, a random two-character salt is generated for each call.

## Description

The filter returns `crypt($value, $salt)`, calling Perl's built-in
`crypt` (the traditional Unix one-way password hash). If a `SALT`
argument is given it is used directly; otherwise Interchange generates a
random two-character salt with `random_string(2)`.

With a random salt the output differs on every call, so the result can be
stored but the plaintext cannot be recovered — you verify a password by
re-crypting the candidate with the stored hash as the salt. With an
explicit salt the output is reproducible.

`crypt` is the classic DES-based hash and is weak by modern standards; for
new password storage prefer [bcrypt](bcrypt.md).

## Examples

With an explicit salt the result is deterministic:

    [filter crypt.AB]TEST[/filter]

produces:

    ABqvR6zZkzeuA

With no salt the result is a fresh hash each time:

    [filter crypt]TEST[/filter]

produces a value such as `x9Kf1uL0aB2yc` (the first two characters are the
randomly chosen salt, and differ on each run).
