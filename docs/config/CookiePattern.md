# CookiePattern

Sets the regular expression Interchange uses to extract the session ID
from the value of the browser's session cookie. Reach for it only when
something other than Interchange writes the cookie value and the default
pattern no longer matches it.

**Scope:** catalog (`catalog.cfg`)

## Syntax

    CookiePattern  REGEX

A regular-expression string (`parse_regex`), validated for syntax at
configuration time. Default: `[-\w:.]+`.

## Description

Interchange's own session cookie value is the session ID followed by a
colon and an IP address, username, or domain fragment. When a request
arrives, Interchange matches the cookie named by
[CookieName](CookieName.md) against this pattern to recover just the
session ID:

```perl
$CGI::cookie =~ m{$::Instance->{CookieName}=($Vend::Cfg->{CookiePattern})};
```

The captured text becomes the session ID. The default `[-\w:.]+` accepts
the word characters, hyphen, colon, and dot that Interchange itself puts
in the cookie. You only change it when the cookie value is generated by
another program whose format differs.

## Examples

Match an 8-to-32-character session ID written by an external program:

```
CookiePattern \w{8,32}
```

## Notes

A too-loose pattern can capture trailing cookie content (the IP or
username part), producing a session ID that never matches an existing
session. Match only the ID portion your cookie writer emits.

If you change [CookieName](CookieName.md) but keep Interchange's own
cookie format, leave `CookiePattern` at its default -- the default already
matches Interchange-written values.
