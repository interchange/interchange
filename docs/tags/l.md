# l

`[l]` is an alias of [loc](loc.md). See [loc](loc.md) for full
documentation.

    [l] message [/l]
    [l LOCALE] message [/l]

It localizes (translates) the interpolated body through Interchange's locale
message tables, returning the source text when no translation exists.

## Source

Defined in `code/UserTag/loc.tag` via `UserTag l Alias loc`, which registers
`l` as an alias of [loc](loc.md).
