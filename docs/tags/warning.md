# warning

`[warning]` is an alias for [warnings](warnings.md). It takes the same
attributes and behaves identically; see that page for full documentation.

    [warning message="Please double-check your address."]

is the same as:

    [warnings message="Please double-check your address."]

## Source

Defined as an alias in `code/SystemTag/warnings.coretag`
(`UserTag warning Alias warnings`).
