# strip

Remove leading and trailing whitespace from its body. Reach for it when
template indentation or surrounding newlines would otherwise leak into output,
attribute values, or comparisons.

## Syntax

    [strip]BODY[/strip]

Container tag. The body is interpolated first (ITL inside it is processed),
then whitespace is trimmed from both ends of the result.

## Attributes

None. The tag takes no attributes and no positional parameters
(`PosNumber 0`).

## Description

The tag applies two substitutions to the body: `s/^\s+//` and `s/\s+$//`.
Only the outermost leading and trailing whitespace (spaces, tabs, newlines) is
removed; whitespace inside the body is left untouched. The trimmed string is
returned.

This is useful when a value is generated by a multi-line ITL block whose
indentation you do not want in the output, for example when building an
attribute value, a header, or a token to compare against.

## Examples

Trim a value assembled across several indented lines:

    [strip]
        [scratch coupon_code]
    [/strip]

If `coupon_code` holds `SAVE10`, the tag returns:

    SAVE10

Whitespace between words is preserved; only the ends are trimmed:

    [strip]   two   words   [/strip]

produces:

    two   words
