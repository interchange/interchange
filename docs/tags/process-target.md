# process-target

> **Alias:** `process-target` is an alias for [process](process.md). Use
> [process](process.md) instead.

`[process-target]` invokes the same tag as [process](process.md) — it returns
the URL a form should submit to. The alias exists for backward compatibility;
see [process](process.md) for syntax, attributes, and examples.

## Source

Declared as `UserTag process-target Alias process` in
`code/SystemTag/process.coretag`.
