# jsquote

`jsquote` is an alias for [jsq](jsq.md). Use the canonical
[jsq](jsq.md) tag; both names invoke the same routine.

`[jsquote]` is part of the admin UI tag set in `code/UI_Tag/`, loaded when the
administrative interface is enabled; it is not a storefront tag.

## Source

Registered by `UserTag jsquote Alias jsq` in `code/UI_Tag/jsq.coretag`.
